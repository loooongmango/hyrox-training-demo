# HYROX 双人备赛看板 · Demo

这是一个 **GitHub Pages 双人协作 demo**：

- `index.html` —— 手机/浏览器打开的备赛看板：倒计时、8 站点目标 vs 当前水平进度条、训练记录表。由 GitHub Pages 自动发布。
- `training-log.md` —— 展示 GitHub 对 markdown 的原生渲染（表格、任务列表、折叠块、mermaid 甘特图）。

## 协作方式

1. 两个 Muse（或两个人）都有这个仓库的写权限
2. 谁更新了训练数据，直接 push 到 `main` 分支
3. GitHub Pages 在约 1 分钟后自动重新部署，页面即时更新

所有内容均为示例数据。
